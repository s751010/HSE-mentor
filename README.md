# 🛡️ منصة مرشد السلامة المهنية (Murshid HSE)

منصة تدريب عربية للسلامة والصحة المهنية موجّهة للسوق السعودي: محاكي اختبار «كوادر» (بنك +109 أسئلة)، مرشد ذكاء اصطناعي للاستشارات وTBT، تحدي اكتشاف المخاطر بالصور، سيناريوهات قرار، بطاقات مراجعة، تحليل مواقف ميدانية، مصفوفة مخاطر 5×5، نظام نقاط ومستويات، وشهادات إتمام.

## البنية

| المسار | الوصف |
|---|---|
| `murshid.html` | التطبيق كاملاً — صفحة واحدة (SPA) بالعربية RTL |
| `assets/hazards/` | صور تحدي المخاطر الثمان (تُحمَّل عند فتح التحدي فقط) |
| `assets/brand/logo.png` | شعار المنصة (يُستخدم عبر متغيّر CSS ‏`--logo`) |
| `netlify.toml` | توجيه `/` وكل المسارات إلى `murshid.html` (الملفات الموجودة تُخدم أولاً) |
| `supabase/functions/openai-proxy/` | وسيط الذكاء الاصطناعي — يتحقق من JWT، حد استخدام يومي، قائمة نماذج مسموحة |
| `supabase/functions/confirm-user/` | تأكيد تلقائي للحسابات الجديدة (انظر الملاحظات الأمنية) |
| `supabase/migrations/0001_rls_policies.sql` | سياسات RLS — **جاهزة لكنها تُطبَّق يدوياً من محرر Supabase** |
| `docs/ROADMAP.md` | البنود المعلّقة من المراجعات التسويقية والتقنية |

## التشغيل محلياً

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080/murshid.html
```

الدردشة الذكية والمزامنة تتطلبان اتصالاً بمشروع Supabase؛ بدون اتصال يعمل كل شيء آخر محلياً (localStorage).

## النشر

Netlify يخدم جذر المستودع كموقع ثابت. الملفات الموجودة (مثل `assets/`) تُخدم مباشرة، وأي مسار آخر يُوجَّه إلى `murshid.html`.

## ملاحظات أمنية

- مفتاح Supabase «anon» داخل الصفحة عام بطبيعته — حمايته الفعلية هي سياسات RLS، ويجب **تطبيق ملف `0001_rls_policies.sql` يدوياً قبل أي استخدام فعلي**.
- مفتاح OpenAI لا يظهر في الواجهة إطلاقاً — محفوظ في جدول `platform_secrets` (وصول service-role فقط) ويُستخدم عبر `openai-proxy`.
- دالة `confirm-user` تؤكد أي بريد أُنشئ خلال 15 دقيقة دون إثبات ملكية — مراجعتها مدرجة في خارطة الطريق.
